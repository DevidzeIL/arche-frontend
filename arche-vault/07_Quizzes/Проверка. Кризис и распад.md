# Проверка. Кризис и распад

Оси с пятой по седьмую: граница разума, распад субъекта, язык и власть.

## Почему вещь в себе у Канта недоступна?

- [ ] Приборы пока недостаточно точны
- [x] По устройству познания: мы видим мир только в собственных формах — пространстве, времени, причинности
- [ ] Бог скрыл её от человека
- [ ] Кант не успел закончить исследование

> Это не слабость, которую можно преодолеть, а граница, предъявленная самим разумом. Опровергнуть её нечем — с ней можно только жить.

## Чем Французская революция скомпрометировала разум?

- [ ] Доказала логическую ошибку в его основаниях
- [x] Исходом: разумный проект, применённый к обществу, кончился террором
- [ ] Запретила науку
- [ ] Ничем — она его прославила

> Разум не был опровергнут теоретически. Он был скомпрометирован практикой — и это оказалось убедительнее любого аргумента.

## Когда, по Шиллеру, человек «вполне человек»?

- [ ] Когда рассуждает строго логически
- [ ] Когда исполняет долг
- [x] Когда играет — в состоянии, где чувство и разум не воюют
- [ ] Когда трудится

> Игра у Шиллера — не отдых, а единственное свободное отношение к предмету: без нужды и без принуждения. Собрать расколотого человека может только то, что не заставляет.

## Кто НЕ входит в «трёх мастеров подозрения»?

- [ ] Маркс
- [ ] Ницше
- [ ] Фрейд
- [x] Хайдеггер

> Формула Рикёра: Маркс (сознание определяется положением), Ницше («я» — обман грамматики), Фрейд («я» не хозяин в своём доме). Хайдеггер бьёт по субъекту иначе — через «уже-в-мире».

## «Я мыслю» у Ницше — обман чего?

- [x] Грамматики: раз у глагола должно быть подлежащее, деятель присочиняется к деянию
- [ ] Зрения
- [ ] Памяти
- [ ] Священников

> Нет «бытия» позади поступка. Деятель — довесок, которого требует язык, а не реальность.

## Средний из «трёх ударов по самолюбию человека» (по Фрейду) — чей?

- [ ] Коперника
- [x] Дарвина: человек — не отдельное творение, а животное среди животных
- [ ] Ньютона
- [ ] Самого Фрейда

> Коперник лишил человека центра мира, Дарвин — особой природы, психоанализ — привилегированного доступа к самому себе.

## Где проходит граница между модернизмом и постмодернизмом?

- [ ] В 1950 году, по календарю
- [ ] В использовании новых материалов
- [x] В отношении к утраченной целостности: модернизм ещё верит, что её можно собрать формой, постмодерн — что собирать нечего
- [ ] В отказе от искусства вообще

> Не набор приёмов, а отношение к задаче. Джойс строит связность приёмом; постмодерн отвечает: исходной цельности и не было.

## «Нет ничего вне текста» у Дерриды означает…

- [ ] Реальности не существует
- [ ] Все книги говорят одно и то же
- [x] Нет позиции вне всякого контекста, с которой можно сверить слова с вещами напрямую
- [ ] Читать бесполезно

> Самое стойкое недоразумение вокруг Дерриды. Он всю жизнь объяснял: читая, мы уже внутри языка, и выйти из него, чтобы взглянуть «со стороны», нельзя.

## Схема паноптикума у Фуко — про что?

- [ ] Про устройство тюрем XVIII века, и только
- [x] Про власть, которая работает самонадзором: человек, который может быть виден всегда, надзирает за собой сам
- [ ] Про архитектурную акустику
- [ ] Про недостаток тюремных бюджетов

> Башня в центре, камеры по кругу, надзиратель не нужен. Фуко: так устроены школа, казарма, больница — и во многом мы сами.

## Возражение, на которое у «конца метанарративов» нет хорошего ответа:

- [ ] Большие рассказы слишком длинные
- [x] «Больше нет больших рассказов» — само по себе большой рассказ
- [ ] Люди любят истории
- [ ] Наука его опровергла

> Утверждение о конце всех метанарративов претендует на ту же всеобщность, которую отрицает. Это самое слабое место конструкции — и держать его в уме полезно.
