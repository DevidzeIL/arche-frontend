# Arche — личная энциклопедия культуры и философии

Obsidian-хранилище с заметками превращается в статичный сайт: каталог с поиском,
интерактивный таймлайн и граф связей. Бэкенда нет — заметки вшиваются в бандл на этапе сборки.

## Запуск

```bash
pnpm install
pnpm dev        # http://localhost:5177
```

Команды:

| Команда | Что делает |
| --- | --- |
| `pnpm dev` | Dev-сервер с hot reload |
| `pnpm build` | Проверка типов + production-сборка в `dist/` |
| `pnpm preview` | Локальный просмотр собранного `dist/` |
| `pnpm typecheck` | Только проверка типов |
| `pnpm lint:vault` | Проверка хранилища: дубли id, битые ссылки, пропавшие картинки, поправки границ |
| `pnpm borders` | Пересобрать исторические границы в `public/borders/` (см. [Границы](#границы)) |
| `pnpm context` | Пересобрать фон «а в это время» и сведения о государствах из Wikidata в `public/context/` (`--only=events,people,polities` — по частям) |
| `pnpm kb` | Пересобрать базу знаний — войны, течения, религии, народы, эпохи, связи влияния — и привязку заметок к Wikidata в `public/kb/` |

## Разделы

- **Главная** — каталог по типам, поиск и фильтры (состояние живёт в URL, ссылкой
  можно делиться), плюс «Недавнее» — вернуться к тому, что читали
- **Карта** (`/timeline`) — главный экран: узлы на оси времени и типизированные
  связи между ними. Отвечает не на «что и когда», а на «из чего возникло и к чему привело»
- **Глобус** (`/globe`) — где всё это происходило: места на шаре или плоской
  карте, исторические границы на выбранный год, дуги влияния и фон «а в это
  время». Подробности — [ниже](#глобус)
- **Листать** (`/feed`) — лента фрагментов: зашёл, прочитал один блок, пошёл
  дальше. Подробности — [ниже](#лента-фрагментов)
- **Сегодня** (`/study/today`) — главный экран для ежедневных занятий: маленькая
  стопка карточек, заметка дня и цепочка закрашенных дней. Подробности —
  [ниже](#ежедневная-практика)
- **Учёба** (`/study`) — курсы, тесты, экзамены и «что даётся тяжело» —
  темы, которые чаще всего забываются, с отдельной стопкой на повторение. Курс собирается
  из хаба: главы — это разделы «## … ось …», уроки — их нумерованные списки.
  Вопросы генерируются из причинных связей графа, объяснение к ответу — подпись
  связи из заметки. Прогресс (XP, стрик, карточки повторения) хранится локально,
  переносится экспортом/импортом JSON с той же страницы
- **Что читать** (`/reading`) — литература из заметок, разложенная по осям
  вектора, с отметкой прочитанного. Подробности — [ниже](#литература)
- **Что стоит дописать** (`/health`) — где хранилищу не хватает данных, чтобы
  работать во всех разделах. Подробности — [ниже](#что-стоит-дописать)
- **Написать** (`/contact`) — обратная связь через Netlify Forms.
  После деплоя включите Form detection: Site configuration → Forms
- **Заметка** (`/note/:id`) — свой шаблон для персон, работ, концепций, эпох
  и мест, плюс блок «Возникло из / Привело к / Сюда ссылаются». У персон, работ
  и событий — «Где и когда»: место, государство в тот год и карта границ

На телефоне четыре ежедневных раздела вынесены в нижнюю панель — одно касание
вместо бургер-меню. Остальное осталось в меню сверху.

Ежедневные занятия можно начинать не с начала вектора: на странице «Учёба»
выбирается ось, с которой пойдёт заметка дня. Оси до неё не выбрасываются —
лента вернётся к ним, дойдя до конца.

Каталог фильтруется и по годам: диапазон живёт в адресе, рядом готовые периоды.
На странице заметки видно её место в курсе и следующий урок.

Горячие клавиши: `⌘K` / `Ctrl+K` или `/` — поиск, `Esc` — снять выделение на карте,
`Пробел` — показать ответ карточки, `1`–`4` — оценить себя.

## Литература

В заметках лежит раздел «Что читать» (старое название «Источники / Литература»
тоже понимается). Записи размечаются видом:

```markdown
## Что читать

- {первичный} Платон — «Апология Сократа», «Критон», «Федон»
- {проводник} [Socrates — Stanford Encyclopedia of Philosophy (англ.)](https://plato.stanford.edu/entries/socrates/)
- {обзор} Тарнас — «История западного мышления», гл. 1
```

Виды: `первичный` — сам текст, `проводник` — помогает в него войти,
`обзор` — общая картина, `контекст` — смежное. Старый формат с суффиксом
`(первичный)` в конце строки продолжает работать.

**Почему ссылки, а не текст.** Соблазн наполнить хранилище выдержками из
открытых источников велик, но чужой энциклопедический абзац ломает то, ради
чего заметки писались: правила требуют человеческого языка и понимания,
а не полноты. К тому же Википедия распространяется под CC BY-SA (заражает
лицензией всё производное), а Stanford Encyclopedia закрыта копирайтом.
Поэтому здесь живут отсылки, а текст остаётся своим.

Раздел `/reading` собирает всю литературу хранилища и раскладывает по осям:
видно, что читать по текущей теме и сколько первоисточников уже прочитано.
Отметки хранятся вместе с остальным прогрессом.

## Что стоит дописать

Каждая возможность приложения чем-то питается: карта — датировкой, глобус —
географией, родословная и вопросы тестов — причинными связями, повторение —
карточками. Заметка без датировки не сломана — она просто не видна на карте,
и понять это, глядя на саму заметку, нельзя.

Рядом с каждой заметкой — кнопка, кладущая в буфер путь к файлу и заготовку
строки (`place: [ ]`, `start_year:`). Приложение остаётся read-only: править
всё равно в Obsidian, но искать файл и вспоминать название поля больше не нужно.

Раздел считает такие пробелы и складывает в списки со ссылками: без датировки,
без географии, без причинных связей, на них никто не ссылается, совсем короткие,
источник не указан, вне границ (город в свой год не попал ни в одно
государство — чинится заплаткой в `_borders`). Плюс полосы охвата — сколько
заметок попадает на карту, на глобус, в родословную и в исторические границы.
Места и хабы в датировке не считаются: своего года у них нет, и это не пробел.

Хаб ведёт раздел «Чего здесь пока нет» руками; здесь то же самое, но про каждую
заметку и без ручной работы.

## Устанавливается на телефон

Приложение — PWA: ставится на домашний экран и открывается без адресной строки,
с ярлыками сразу в «Сегодня» и «Листать». Заметки и так вшиты в бандл, поэтому
офлайн даётся почти даром — кэшируется сам бандл.

Изображения хранилища в предзагрузку **не** попадают: их около сорока и весят
они 22 МБ против 1,7 МБ у приложения. Скачивать это при первом заходе было бы
издевательством, поэтому они кэшируются по мере просмотра. Границы и фон
«а в это время» — так же: просмотренные века работают без сети, остальные
докачиваются.

Тяжёлые экраны грузятся по требованию: глобус тянет `d3-geo` с очертаниями суши,
карта — свой рендер, страницы с текстом — react-markdown. Первая загрузка после
разделения — около 350 КБ в gzip вместо 470.

## Глобус

Карта отвечает на «когда и из чего», глобус — на «где». Вместе они собирают
третье измерение: видно, что мысль не висит в воздухе, а переезжает из города
в город вместе с людьми.

| Действие | Что делает |
| --- | --- |
| Перетаскивание | Поворот шара; на карте — прокрутка |
| Колесо мыши, щипок | Приближение (на карте — к курсору) |
| Клик по месту | Что здесь произошло, его связи и чья это была земля в этот год |
| Клик по государству или столице | Флаг, столица, правители, предшественники и преемники, справка и заметки хранилища внутри его границ |
| Клик по ромбу или кружку | Событие или человек из фона «а в это время»: изображение, справка, что рядом в хранилище |
| ▶, пробел | Проигрывает историю: места зажигаются, границы ползут |
| Ползунок | Год, на который смотрим. Шкала неравномерная: недавним векам больше места |
| ‹ ›, стрелки ← → | Год на шаг — год, десятилетие или век (шаг — в настройках) |
| Щелчок по году | Ввести год руками: «1781» или «428 до н.э.» |
| Поиск | Страна, город, заметка, событие, человек, война, течение — найти и перелететь |
| Шар / Карта | Ортографическая проекция или Natural Earth — вся Европа разом |
| Настройки | Слои, раскраска, какие события и каких людей показывать, плотность точек, шаг и скорость |
| Ленты | Эпохи, течения, войны и правители выбранного государства — кто был чьим современником |
| А в это время | Что происходило в выбранный год: своё, крупнейшие державы, события, люди |
| ← в панели | Назад по цепочке переходов: государство → правитель → война |

**Раскраска.** Карту можно перекрасить не по государствам, а по государственной
религии, языку или форме правления — по сведениям Wikidata. Подписи там
разнобойные («католицизм», «Римско-католическая церковь»), поэтому они
раскладываются по семьям с постоянными цветами: Франция в 1600 и в 1700 году
окрашена одинаково, и граница Реформации видна сразу. Религия берётся из
«официальной религии» (P3075), а не из перечня вер подданных — иначе
Османская империя оказалась бы православной. Если официальных несколько и
они из разных семей, государство блёкло-синее, «несколько конфессий»: порядок
в Wikidata ничего не значит, и выбирать первую было бы выдумкой. Семья не
показывается раньше, чем возникла: лютеранство — не раньше 1517 года. Где
сведений нет — государство серое; легенда слева показывает, что есть на
карте сейчас.

**Война на карте.** Найдите войну в поиске или в лентах — её участники
подсветятся, остальные приглушатся, сражения встанут красными метками
с подписями, год сдвинется к её началу.

**Состояние — в адресе.** Год, вид, раскраска, выбранное и война пишутся в адрес:
`/globe?year=1757&war=Q33143` — этим видом можно поделиться. Настройки
запоминаются в браузере.

Со страницы заметки глобус открывается по ссылке «На глобусе» сразу на нужном
годе и с повёрнутым к месту шаром: `/globe?year=1781&place=place-konigsberg-001`.

Города — точки, страны и регионы — размытые пятна: у «Германии» нет координат
в том же смысле, что у Кёнигсберга, и рисовать её точкой значило бы врать
точностью. Дуги между местами — те же причинные связи, что рисует карта,
в цветах типов связи. При выбранном месте показываются только его дуги:
иначе Европа затягивается сеткой, из которой ничего не прочитать.

Шар вращается сам, пока его не трогают; при приближении вращение выключается.

### Как заметка попадает на глобус

Координаты живут **только** в заметках-местах (`type: place`), остальные
заметки ссылаются на место по названию. Дублировать широту и долготу в каждой
персоне значило бы завести второй источник истины, который немедленно
разойдётся с первым.

```markdown
---
id: place-konigsberg-001
type: place
lat: 54.71
lon: 20.51
scale: city          # city | region
aliases: [Кёнигсберг, Восточная Пруссия]
---
```

Порядок источников — тот же, что у датировок:

1. `place: [Афины, Париж]` во frontmatter — основной способ
2. Строка шапки: `**Страна / культура:** Кёнигсберг, Восточная Пруссия`
   или `**Место:** Европа — Польша, Италия`. Названия и синонимы ищутся
   с учётом падежей: «преподавал в Париже» находит Париж
3. Работы наследуют места автора: «Левиафан» написан там, где жил Гоббс

Заметка без места на глобус не попадает, но остаётся везде остальном: у мысли
не всегда есть точка на карте, и притворяться, что есть, незачем. Сейчас
география разрешается у 59 заметок из 132.

Очертания суши — набор 110m (55 КБ), вшитый в бандл вместе с заметками:
тянуть тайлы со стороннего сервера значило бы завести зависимость от чужой
доступности ради фона под точками. Границы по той же причине лежат в самом
приложении, а не на чужом сервере.

## Границы

Глобус показывает не только где, но и чья это была земля: около 1 600
государств с 3400 года до н.э. по 2024-й, границы меняются вместе с ползунком.
Страница Канта говорит «Кёнигсберг — Королевство Пруссия, 1724», страница
Кёнигсберга — всю цепочку от Тевтонского ордена до России.

**Откуда данные.**

| Слой | Набор | Лицензия |
| --- | --- | --- |
| Государства | [Cliopatria](https://github.com/Seshat-Global-History-Databank/cliopatria) (Seshat Global History Databank), v0.2.1 | CC BY 4.0 |
| Народы и культуры там, где государств нет | [historical-basemaps](https://github.com/aourednik/historical-basemaps) | GPL-3.0 |
| Русские названия государств | Wikidata | CC0 |

Файлы фона в `public/borders/bg/` — производные от historical-basemaps и
распространяются под GPL-3.0, как и исходник. Код приложения от них не зависит:
это отдельные данные, которые грузятся по сети.

**Это реконструкция, а не съёмка.** Границы упрощены до пяти километров,
шаг по времени у набора неровный, в древности всё приблизительно. Интерфейс
это не прячет: у панели государства подпись «по данным Cliopatria —
приблизительно», город у самого края упрощённой границы помечается «у границы»,
а народы фона — «здесь жили», а не «здесь правили».

**Как устроено.**

- `pnpm borders` скачивает наборы закреплённых версий, упрощает геометрию
  (mapshaper), режет по векам и кладёт TopoJSON в `public/borders/`: 2 МБ
  в gzip на всю историю, от 15 КБ (V век до н.э.) до 300 КБ (XIX век) на век.
  Глобус тянет только тот век, на который смотрят, и следующий — заранее
- Русские названия ищутся через статью Википедии, а не через идентификатор
  Wikidata из набора: идентификаторы там местами ошибочны («Republic of Korea»
  помечена как КНДР, «Syria» — как Ассирия), а ссылка на статью — нет.
  Где Wikidata молчит или подписывает не то («Danish Magnates» → «Кристофер II»),
  выручает ручной словарь `scripts/data/polity-names.ru.json`: русское
  название есть у всех 1 587 государств
- Чья это земля у каждого города — считает плагин `vite/borders.ts` при
  запуске и сборке: для ответа нужны границы всех веков (10 МБ), а сам ответ —
  десяток отрезков на место. Только для городов: у «Германии» точка на
  глобусе — условный центр, и ответ про неё был бы ответом про Тюрингию
- Пока шар вращается, рисуется упрощённая копия границ: на ходу деталей
  не разглядеть, а точек втрое меньше

**Когда набор ошибается.** Ошибки есть, и именно там, где хранилищу важно:
у Cliopatria нет классических Афин (Сократ жил бы «нигде») и нет Женевы
(Руссо оказался бы подданным Савойи). Поправки живут в хранилище, в
`arche-vault/_borders/`, и подхватываются без пересборки границ.

`patches.geojson` — государство, которого нет или которое набор путает:

```json
{
  "type": "Feature",
  "properties": {
    "name": "Republic of Geneva",
    "ru": "Женевская республика",
    "from": 1536,
    "to": 1798,
    "note": "Почему понадобилась поправка"
  },
  "geometry": { "type": "Polygon", "coordinates": [[[6.03, 46.27], "…"]] }
}
```

Необязательные поля: `polity` — если земля на самом деле принадлежит
государству из набора (Женева после 1815 года — Швейцарии), `within` —
объединение, в которое она входила (`"(Holy Roman Empire)"`), `draw: false` —
поправка только для ответа «чья это земля», без полигона на карте. Последнее
нужно для оккупаций: Греция 1941–1944 годов на карте и так закрашена
Германией, и квадрат «Греция под оккупацией» поверх неё соврал бы о границах
ради правды в одной строке. Полигон проще всего нарисовать на
[geojson.io](https://geojson.io).

Сейчас в файле около сорока поправок — все найдены сверкой каждого города
хранилища по всем векам. Пруссия не входила ни в Рейнский, ни в Германский союз;
Торунь был орденским до 1454 года и польским до 1793-го; Флоренция с 1532 года —
не республика; Вена и Прага при Фердинанде I — не Испания; после 1945 года
Восточная Германия — зона оккупации, а не СССР. Объяснение каждой — в поле `note`,
оно же показывается в панели государства на глобусе.

`names.json` — поправки к названиям, в том числе по годам:

```json
{
  "Greek City-States": "Греческие полисы",
  "Weimar Republic": [
    { "to": 1932, "ru": "Веймарская республика" },
    { "from": 1933, "ru": "Нацистская Германия" }
  ]
}
```

`pnpm lint:vault` проверяет оба файла: опечатка в `polity` иначе молча не
сработала бы.

## А в это время

Хранилище — заметки своими словами, и тысячу событий в нём никто писать не
будет. Но пустота вокруг Канта врёт не меньше выдуманной точности: в 1755 году
он пишет «Всеобщую естественную историю неба», а Лиссабон в тот же год лежит
в руинах, и Европа спорит о Провидении.

Поэтому на глобусе есть бледный фон: около 2 150 событий (сражения, войны,
договоры, соборы, восстания, бедствия, основание университетов и городов,
постройки) и 4 900 человек — ромбы и кружки поменьше заметок. Берутся из
Wikidata (CC0), и только то, что не является чужим текстом: название, год,
место, короткое описание вроде «немецкий философ» и ссылка на статью. Это тот
же принцип, что у [литературы](#литература): ссылка, а не выдержка.

Сколько точек видно, зависит от приближения: на общем виде — полсотни самых
известных, вблизи — сотни, а вместе с ними появляются подписи событий,
людей и столиц.

**Сведения о государствах** — тоже Wikidata: столица на выбранный год, форма
правления, языки, религия, флаг и герб с Commons, предшественники и преемники
(по ним можно перейти — год сам сдвинется туда, где тот существует) и
правители с годами, выбранный год подсвечен. Сведения есть у 1 456 государств,
столица — у 1 021, правители — у 308. Правителей Wikidata чаще знает не через
поле «глава государства», а через должность («король Пруссии») и людей,
которые её занимали, — так они и собираются.

**Справка из Википедии.** В панелях государства, события и человека —
вступление статьи русской Википедии (если её нет — английской). Это чужой
текст под CC BY-SA, поэтому он подгружается по требованию, подписан
и в хранилище не попадает никогда: заметки по-прежнему пишутся своими словами.
Без сети блока просто нет. Портреты и изображения событий тоже запрашиваются
при открытии панели — в общем файле они весили бы четверть.

**На страницах заметок.** У персон, работ и событий в «Где и когда» —
«Рядом в то же время»: кто жил неподалёку и что случалось, пока шла жизнь
или писалась работа. У городов — «Ещё отсюда»: кто здесь родился и что
здесь происходило. У Кёнигсберга это Гофман, Кирхгоф и Гильберт, у Канта —
Гердер и Семилетняя война. На карте-таймлайне подсказка к заметке говорит,
где это было и чья это была земля.

| Файл | Что | gzip |
| --- | --- | --- |
| `public/context/events.json` | События | 136 КБ |
| `public/context/people.json` | Люди | 320 КБ |
| `public/context/polities.json` | Сведения о государствах, столицы | 115 КБ |
| `public/context/rulers.json` | Правители — грузится при первом выборе государства | 69 КБ |

- Заметность — по числу языковых версий статьи; пороги в
  `scripts/build-context.mjs` подобраны так, чтобы фон не забивал карту.
  Основание городов — только до 1500 года и с пониженным весом: статей
  о городах столько, что иначе Сыктывкар (1780, год получения статуса)
  обгонял бы Вестфальский мир
- Если человек уже есть в хранилище, фоновая точка для него не рисуется
- «В это время» — окно, растущее вглубь истории: ±10 лет для XIX века,
  ±60 для античности
- Человек стоит на месте рождения — так в Wikidata; где он работал, знает
  только заметка

## Энциклопедия связей

Глобус показывал точки — событие здесь, человек там. Но история держится
на связях: война — это участники, сражения, причины и итоги; течение — люди,
которые к нему принадлежали, и те, на кого они повлияли. Всё это в Wikidata
есть, под CC0 и без чужого текста — названия, годы и ссылки между элементами.

`pnpm kb` собирает это в `public/kb/`:

- **войны** — стороны и отдельно лица (монархи, полководцы: в Wikidata они
  в одном списке со странами), сражения (с координатами — встают на карту), число
  погибших, причины и последствия. Причины в Wikidata указаны редко, у пары
  десятков войн, — там, где их нет, страница так и говорит и отсылает к справке;
- **течения** в философии, искусстве, литературе и архитектуре — годы, откуда,
  основатели и представители;
- **религии и конфессии** — основатели, от чего отделились, ветви, в каких
  государствах были государственными;
- **народы** — языки, религии, численность;
- **эпохи** — годы, что было до и после, из чего состоят;
- **кто на кого повлиял** — связи между людьми, их течения.

**Страница справки** `/kb/<id>` — у любой сущности: войны, государства,
течения, человека, события. Факты, вступление Википедии, изображение,
мини-карта, связанные сущности — каждая ведёт на свою страницу — и заметки
хранилища рядом. Получается сеть, по которой можно идти от чего угодно
к чему угодно: от Семилетней войны к Пруссии и её королям, от Руссо —
к Канту, на которого он повлиял, и дальше к Гегелю и Хайдеггеру. Поиск ⌘K находит справки
наравне с заметками, ниже них.

**Заметки в большой картине.** Скрипт подбирает каждой заметке элемент
Wikidata — по названию, с проверкой типа: персона должна быть человеком,
место — иметь координаты. Привязка лежит в `public/kb/vault.json`, сами
заметки не трогаются. Если скрипт ошибся, в заметке пишется
`wikidata: Q9312` — ручное поле сильнее, а `wikidata: none` отвязывает заметку совсем. После этого у заметки появляется
блок «В большой картине»: у Канта — течения, кто на него повлиял и на кого
повлиял он (заметки хранилища — первыми и жирным), у войны — участники
и причины, у течения — представители.

## Лента фрагментов

Раздел для другого настроения: не заниматься, а просто читать по чуть-чуть.

**Атом ленты — раздел заметки, а не заметка.** Правила хранилища требуют
«не более 1–2 экранов текста на раздел», поэтому разделы уже написаны как
самостоятельные куски: медиана — около четырёхсот знаков, то есть ровно
один экран телефона. Резать и склеивать ничего не нужно, лента достаётся
из vault'а даром. Сейчас в ней 437 фрагментов.

**Порядок не случайный.** Следующий фрагмент берётся у соседа по графу,
и переход подписывается тем же объяснением, что рисует карта:

```
Сократ  →  ученик, через которого мы его и знаем
[ Платон · Персона · 428 до н.э. ]
```

Так пролистывание превращается из потока разрозненных фактов в дрейф
по родословной. Через четыре шага по одной ветке лента уходит в другую
часть графа — иначе она застревала бы в одном кластере; смена помечается
разделителем «другая ветка».

Знакомство с заметкой начинается с её сути: разделы «Кратко», «Суть идеи»,
«О чём» показываются первыми, остальное достаётся на следующих заходах.
Прочитанное запоминается, и лента не гоняет одно и то же по кругу.

Кнопка **«Запомнить»** заводит карточки заметки в интервальное повторение —
завтра они придут в «Сегодня». Это единственная связь между разделами:
читать можно и не занимаясь.

## Ежедневная практика

Раздел устроен под один сценарий: зайти на несколько минут, закрыть маленькую
норму и не порвать цепочку дней.

**Что показывается за день.** Сначала карточки, у которых подошёл срок, потом
немного новых — не больше трети дневной нормы. Ограничение не косметическое:
взять сегодня сорок новых карточек значит получить сорок повторений послезавтра
и бросить всё через неделю. Норма (8 / 15 / 25 / 40) меняется на той же странице.

**Порядок нового материала** берётся из учебной программы, а не случайно: хаб
задаёт последовательность осей, оси — последовательность уроков. Ежедневная
практика идёт по вектору тем же путём, каким его задумал автор vault'а,
только по кусочку в день.

**Заметка дня** — первый непрочитанный урок курса. Прочитали — она сменится.

**Как отвечать.** Карточка спрашивает на воспоминание: сформулируйте ответ
про себя, откройте оборот и оцените себя честно — «Не помню» вернёт карточку
в тот же заход, «Легко» отправит её сразу через коробку. Забытое возвращается
в конец очереди сегодня же, а не завтра.

Вопросы тестов, которые вы уже проходили, попадают в ту же ежедневную стопку
вперемешку с карточками. Старый адрес `/study/review` ведёт сюда же.

### Откуда берутся карточки

Руками они не пишутся — собираются из заметок и графа, по пять видов:

| Вид | Вопрос | Ответ |
| --- | --- | --- |
| Суть | «Логос» — в чём суть? | Первый содержательный абзац заметки |
| Что предшествует | «Логос» — что этому предшествует? | Предки по графу с подписями связей |
| К чему ведёт | «Логос» — к чему это ведёт? | Потомки по графу |
| Авторство | «Левиафан» — кто автор? | Персона по связи `автор` |
| Датировка | Сократ — годы жизни? | `start_year` / `end_year` из frontmatter |

Датировка спрашивается **только** при явных полях во frontmatter: разбор дат
из текста — фолбэк для раскладки на карте, там ошибка сдвигает узел, а здесь
превратилась бы в заученную неправду.

### Свои карточки

То, что автоматика вытащить не может, пишется в самой заметке — раздел
`## Карточки`, по строке на карточку, лицевая сторона и оборот через `::`:

```markdown
## Карточки

- Что означает ньютоновское «гипотез не измышляю»? :: Отказ объяснять природу тяготения: наука соглашается описывать, не доходя до последних причин
- Что уходит из объяснения природы после Ньютона? :: Цель. Камень больше не стремится к своему месту, он падает по формуле
```

Раздел не показывается на странице заметки как есть — вместо него выводится
блок «Что запомнить» с закрытыми ответами.

### Ответ своими словами

По умолчанию карточка просит **написать** ответ, а не вспомнить его про себя.
Разница не косметическая: перевёрнутая карточка почти всегда выглядит знакомой,
и самооценка уезжает вверх — узнавание выдаёт себя за знание. Написанная фраза
этого не позволяет: пробелы видно сразу, и видно их вам, а не приложению.

Что из этого следует:

- после сверки ваш ответ стоит рядом с авторским — сравнивать удобнее, чем
  вспоминать, что вы имели в виду;
- при следующей встрече с той же карточкой показывается прошлая формулировка:
  «12 августа вы объясняли это так»;
- на странице заметки появляется раздел «Своими словами» — все ваши ответы
  по этой теме, свежие первыми.

Последнее и есть главное. Заметка стоит на месте, а список растёт: по нему видно
движение, которого ни серия дней, ни XP не показывают. Если ваша формулировка
вышла точнее авторской — её стоит перенести в текст, кнопка правки рядом.

Письменный ответ предлагается там, где ответ надо построить: суть, родословная
идеи, свои карточки. Датировку и авторство набирать руками незачем — там ответ
в два слова. Режим выключается переключателем на «Сегодня»: с телефона набирать
текст дорого, и заставлять себя не нужно. Хранятся последние три ответа
на карточку.

### Как пользоваться картой

| Действие | Что делает |
| --- | --- |
| Колесо мыши | Масштаб времени вокруг курсора |
| Перетаскивание | Движение по времени и по дорожкам |
| Наведение | Краткая суть заметки и её ближайшие связи |
| Клик | Родословная: возникло из / привело к / противостоит |
| Двойной клик | Открыть заметку |
| Щипок двумя пальцами | Масштаб времени |
| «Путь отсюда» → клик по второй заметке | Цепочка между двумя идеями с объяснением каждого перехода |

Узлы, для подписи которых не хватило места, остаются точками — так видно
настоящую плотность материала. Приблизьте масштаб, и подписи появятся.

### На телефоне карта выглядит иначе

Ниже 768px по умолчанию открывается **лента**: то же содержимое, развёрнутое
сверху вниз, эпохи — разделами, узлы — карточками с типом, годом, сутью
и строкой «к чему ведёт». Тап открывает ту же панель «почему», что и на схеме.

Это не упрощение ради телефона, а следствие: схема отвечает на «из чего
возникло» одним взглядом, но для этого ей нужна ширина. В 390 точках две
с половиной тысячи лет и пять дорожек превращаются в наложенные друг
на друга подписи — обзора не получается ни у кого.

Схема остаётся доступной переключателем «Лента / Схема» в правом нижнем углу.

## Правка заметок из приложения

На локальном сервере у страницы заметки есть кнопка с карандашом. Она открывает
файл целиком, вместе с frontmatter, и сохраняет его обратно в `arche-vault`.

Зачем это нужно: раньше приложение хранилище только читало. Чтобы поправить
формулировку, приходилось скопировать путь, открыть Obsidian, найти место,
дописать — и это трение объясняет, почему заметки застряли на полутора сотнях
слов. Исправить текст в тот момент, когда стало видно, что он плохой, было
дороже, чем махнуть рукой.

Как устроено:

- ручка записи живёт в плагине dev-сервера (`vite/vault-write.ts`) и в собранное
  приложение не попадает вовсе — не отключена флагом, а физически отсутствует.
  Писать в хранилище можно за своим столом, с телефона — только читать;
- путь проверяется: за пределы `arche-vault` записать нельзя, не-`.md` тоже,
  новые файлы ручка не создаёт;
- `id` во frontmatter менять нельзя: по нему интервальное повторение находит
  карточки заметки, и подмена молча обнулила бы всю статистику по ней;
- `updated:` проставляется само;
- frontmatter правится текстом, а не разбором YAML: пересборка переставила бы
  ключи и сняла кавычки, превратив diff в кашу;
- несохранённый черновик остаётся в браузере — правка того же файла в Obsidian
  роняет полную перезагрузку страницы, и терять из-за неё текст незачем;
- кнопка «+ карточка» дописывает строку `вопрос :: ответ` в раздел
  `## Карточки`, создавая его перед списком литературы, если раздела ещё нет.

Свои сохранения перезагрузку не вызывают: заметка обновляется в памяти сразу.
Правки из Obsidian — вызывают, как и раньше.

## Как добавить заметку

Создайте `.md` в подходящей папке `arche-vault/`:

```markdown
---
id: person-plato-001
type: person
domain: [philosophy]
status: seed
start_year: -428
end_year: -348
year_precision: approximate
created: 2026-01-03
---

# Платон

**Годы жизни:** 428/427–348/347 до н.э.

Ученик [[Сократ|Сократа]], учитель [[Аристотель|Аристотеля]].
```

### Поля frontmatter

| Поле | Обязательно | Значения |
| --- | --- | --- |
| `id` | да | Уникальный идентификатор, он же адрес страницы `/note/<id>` |
| `type` | да | `hub`, `time`, `person`, `work`, `concept`, `culture`, `event`, `place`, `note` |
| `domain` | нет | `philosophy`, `history`, `culture`, `religion`, `science`, `literature`, `art`, `education`, `psychology` |
| `status` | нет | Стадия проработки заметки |
| `start_year` | для таймлайна | Год начала. До н.э. — отрицательный: `-428` |
| `end_year` | нет | Год окончания интервала |
| `display_year` | нет | Год, в котором заметка стоит на шкале (по умолчанию выводится, см. ниже) |
| `year_precision` | нет | `exact`, `approximate`, `century` — влияет на формат подписи |
| `lat`, `lon` | для мест | Координаты. Только у `type: place` |
| `scale` | нет | `city` или `region` — точка или размытое пятно на глобусе |
| `aliases` | нет | Как место называют в текстах: `[Кёнигсберг, Восточная Пруссия]` |
| `place` | нет | Явная привязка к местам: `place: [Афины, Париж]` |

### Как считается датировка

Порядок источников, от надёжного к запасному:

1. `start_year` / `end_year` из frontmatter — **основной способ**
2. Датировка из текста заметки: строка `**Годы жизни:** 384–322 до н.э.`, `**Год:** 1795`,
   римские века (`XIV–XVI века`), формы со слэшем (`428/427–348/347 до н.э.`)
3. Для эпох — догадка по названию

Заметка без датировки на таймлайн не попадает, но остаётся в каталоге, поиске и графе.

Год на шкале (`display_year`), если не задан явно: для персон и работ — год начала
(рождение, публикация), для эпох, концепций и течений — середина интервала.

Новый тип заметок добавляется в одном месте — [src/arche/noteTypes.ts](src/arche/noteTypes.ts).
Подписи, цвета, порядок секций, дорожки карты и фильтры подхватят его автоматически.

### Связи: как получается «почему»

Тип связи **не размечается руками** — он выводится из того описания, которое
и так пишется рядом со ссылкой. Формат письма менять не нужно:

```markdown
## Связи

- [[Мифологическое мышление]] — то, от чего происходит переход к логосу
- [[Романтизм]] — кризис, на который отвечает романтизм
- [[Платон]] — влияние платонизма на мысль Августина
- [[Аристотель]] — ученик Платона, развивший и критиковавший его идеи
```

Распознаются: `порождает` (переход, предшествует, приводит к), `развивает`
(ученик, систематизация, продолжение), `кризис` (пределы, утрата, распад),
`ответ на`, `противостоит` (отличие от, критика, вместо), `влияет на`,
`автор`, `эпоха`, `контекст`.

**Направление задаёт время**: связь идёт от того, что появилось раньше,
к тому, что появилось позже. Поэтому «влияние платонизма на мысль Августина»,
записанное в заметке Августина, на карте читается как Платон → Августин.

Если инференс ошибся, тип можно указать явно ведущим маркером:

```markdown
- {противостоит} [[Теоцентризм]] — человек вместо Бога в центре
```

Проверить, что получилось, проще всего на самой карте: клик по узлу
показывает разобранную родословную с исходными описаниями.

## Технологии

React 19, TypeScript, Vite 5, Tailwind 3 + shadcn/ui, React Router 7, Zustand,
react-markdown + remark-gfm.

Карта и глобус рисуются на canvas своим кодом, без библиотек визуализации.
Исключение — `d3-geo` для глобуса и карт границ: отсечение полигонов по видимому
полушарию вручную даёт артефакты на краю шара, и это ровно то место, где своё
решение перестаёт окупаться. Очертания суши берутся из `world-atlas` (набор 110m).
Для сборки границ — `mapshaper` и `fflate`, в приложение они не попадают.
