# Фон «а в это время» и сведения о государствах: источники

Файлы в этой папке собраны скриптом `scripts/build-context.mjs` (`pnpm context`)
из Wikidata — https://www.wikidata.org/ — и распространяются на её условиях:
Creative Commons CC0 1.0 (общественное достояние).

| Файл | Что |
| --- | --- |
| `events.json` | События: название, годы, координаты, короткое описание, ссылка на статью |
| `people.json` | Люди: имя, годы жизни, место рождения и смерти, короткое описание, ссылка на статью |
| `polities.json` | Государства: столица, форма правления, языки, религия, флаг и герб, предшественники и преемники |
| `rulers.json` | Правители государств с годами |

Чужого текста здесь нет: только названия, даты, координаты и описания
Wikidata в одну строку. Вступления статей Википедии (CC BY-SA 4.0)
и изображения Wikimedia Commons (лицензия у каждого файла своя)
приложение запрашивает живьём, при открытии панели, и не хранит.
